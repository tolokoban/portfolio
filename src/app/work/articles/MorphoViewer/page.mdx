# MorphoViewer Library

A WebGL library dedicated to 3D visualization of neurons, and used at the **Open Brain Institute**.

One component can display neurons with more than 20 million vertices,
by using an octree/LOD technique and streaming the meshes on the fly.

To prepare all levels of details for an object and slice it in octrees,
I have developped a Blender plugin.
